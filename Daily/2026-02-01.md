## 💭 Technical Decisions & Learnings

### Decision: Token Refresh Strategy
**Problem:** Token expiry could break reminders mid-execution  
**Solution:** Implemented three-tier approach:
1. Pre-flight check (startup)
2. Mid-flight retry (on API error)
3. Dedicated `refreshTokenSafely()` function with timeout

**Learning:** Better to proactively refresh than handle errors reactively

### Decision: Reminder Metadata from Google Calendar
**Problem:** Had to decide whether to use hard-coded reminder times or Google Calendar metadata  
**Solution:** Read from event reminders (custom or default 15 min)  
**Benefit:** Flexible — each event can have different reminder times

### Decision: State Tracking for Duplicates
**Problem:** Cron running every 5 min could send duplicate messages  
**Solution:** Track sent reminders in `calendar-reminders-state.json`  
**Implementation:** 10-minute cooldown per reminder, auto-clean >48h old
