# ⚙️ Cron Job Fix: Email Tagger Auto-Start Proton Bridge

## Problem
**Cron job failed @ 10:00 AM**
- Email Tagger tried to connect to port 1143 (IMAP)
- Connection refused: Proton Bridge not running
- Script crashed

## Solution (Implemented)
Modified `tagger.js` to **detect connection failure and auto-start Proton Bridge**

### What Changed
1. **New function:** `startProtonBridge()`
   - Searches common paths for Proton Bridge binary
   - Spawns process in background (detached)
   - Waits 3 seconds for startup
   - Returns true/false on success

2. **Enhanced error handling in `tagEmails()`**
   - Catches connection errors specifically
   - Detects "ECONNREFUSED" on port 1143
   - Auto-triggers `startProtonBridge()` on first failure
   - Retries connection after bridge startup
   - Prevents infinite retry loops (maxes at 1 retry)

### Code Flow
```
tagEmails() called
  ↓
Try IMAP connection
  ├─ Success → Scan emails → Done ✅
  └─ Fails (ECONNREFUSED)
      ↓
      startProtonBridge()
        ├─ Found binary → Spawn process → Wait 3s ✅
        └─ Not found → Log error ❌
      ↓
      Retry tagEmails() once
        ├─ Success → Scan emails → Done ✅
        └─ Still fails → Report error ❌
```
