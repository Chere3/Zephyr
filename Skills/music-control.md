# 🎵 Music Control Skill

Music player control with playerctl and lyrics lookup. Play, pause, skip tracks, view song info, get lyrics.

---

## 🎯 What It Does

Control any compatible music player + lookup lyrics. Works with Spotify, VLC, MPRIS-compatible apps.

---

## 🛠️ Features

✅ Get current song info  
✅ Play/pause music  
✅ Skip next/previous  
✅ Get song lyrics (Genius)  
✅ Volume control  
✅ Player detection (auto-select)  

---

## 🎮 Commands

```bash
# Current song info
music-info

# Play/pause
music-play
music-pause

# Skip
music-next
music-prev

# Lyrics
music-lyrics
```

---

## 🔗 Compatible Players

- Spotify
- VLC
- MPV
- Rhythmbox
- Audacious
- Any MPRIS-compatible app
