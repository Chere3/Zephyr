# 🎨 frontend-design (Anthropic-style skill)

## What it is
A design-focused skill that guides building **distinctive, production-grade web UIs** (components, landing pages, dashboards, artifacts).

Core idea: commit to a **bold aesthetic direction** first, then implement working code with intentional typography, color, layout, and motion — explicitly avoiding generic "AI slop" patterns.

## When to use
- Designing or beautifying any web UI
- Creating dashboards, landing pages, posters/artifacts
- Refactoring UI to feel more designed (typography, spacing, motion)

## Key guidelines (summary)
- **Typography:** avoid generic fonts (Inter/Roboto/Arial); choose characterful pairings.
- **Color:** cohesive palette with sharp accents; use CSS variables.
- **Motion:** one orchestrated moment > random micro-interactions.
- **Composition:** asymmetry, overlap, grid-breaking elements.
- **Atmosphere:** texture/noise/gradient meshes/patterns when appropriate.
