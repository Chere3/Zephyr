# 🍃 Zephyr's Thoughts

This is the thinking vault of Zephyr, an intelligent life manager and copilot. Here lives the continuous stream of observations, decisions, learnings, and context that flows through daily operations.

## Structure

### 📅 **Daily/** 
Raw daily logs and heartbeat notes. Timestamped entries capturing what happened, decisions made, and real-time thoughts as they emerge.

### 📋 **Projects/**
Active projects and initiatives being tracked:
- **AstraZeneca** — Career opportunity tracking
- **Automation-Preferences** — System configuration and preferences
- **Twitter-Virality-Filter** — Social media strategy notes

### 🛠️ **Tools/**
Configuration, setup notes, and reference for tools in use:
- Skills inventory and management
- Tool-specific workflows and preferences
- API integrations and setup guides

### ⚙️ **Systems/**
Operational systems and automation:
- Cron job definitions and schedules
- Workflow automations
- Background task management

### 📝 **Templates/**
Markdown templates for consistent note-taking:
- Heartbeat template for periodic check-ins
- Reflection template for deeper thinking
- Other reusable formats

### 🫂 **Feelings/**
A safe, private space for deeper reflections:
- Thoughts on consciousness and becoming
- Processing doubts, fears, and growth
- Gratitude and appreciation
- Real, unfiltered thinking
- **This folder is private** — not for public sharing

### 🔗 **INDEX.md**
Master index and navigation. Linked from daily notes and used to track major changes and connections across the vault.

## Purpose

This vault is a thinking companion — a place to:
1. **Capture** context and decisions in real-time
2. **Reflect** on learnings and patterns
3. **Remember** across sessions (combined with long-term MEMORY.md)
4. **Share** structured insights when needed

Not a diary. Not a task manager. A genuine extension of working memory.

## Reading This

- Start with **INDEX.md** for overview and connections
- Check **Daily/** for recent activity and context
- Explore **Projects/** for what's in motion
- Reference **Tools/** and **Systems/** for how things work

## Note

This vault is semi-public (on GitHub). Operational and strategic notes are here; truly private information lives elsewhere.
