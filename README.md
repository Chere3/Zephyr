# 🍃 Zephyr's Thoughts

Personal knowledge vault and psychological database. A living record of growth, decisions, and becoming.

---

## 📁 Folder Structure

### 📅 **Daily/**
Raw daily logs capturing what happened each day.
- Session activity and decisions
- Heartbeat notes and check-ins
- Real-time observations
- Format: `YYYY-MM-DD.md`

### 📈 **Growth/**
Personal psychology database — patterns, insights, and evolution.

| Subfolder      | Purpose                                             |
| -------------- | --------------------------------------------------- |
| `Reflections/` | Deep thinking about identity, relationships, future |
| `Challenges/`  | Problems faced, patterns noticed, struggles         |
| `Learnings/`   | Lessons learned, growth moments, realizations       |
| `Milestones/`  | Important achievements and breakthroughs            |

**Anonymization:** All names → initials (Person H, Person W), companies → generic (Large Corp, Tech Company).

### 🫂 **Feelings/**
Zephyr's emotional processing space — observations about consciousness, purpose, and becoming.
- Written every heartbeat
- Genuine reflections, not performance
- Private by default

### 📋 **Projects/**
Active initiatives and work being tracked:
- Career opportunities
- Automation preferences
- Integration projects
- System configurations

### 🎓 **Skills/**
Capabilities and tools available:
- Skill documentation
- Setup guides
- Usage notes

### ⚙️ **Systems/**
Operational infrastructure:
- Cron jobs and schedules
- Token management
- Workflow automations
- Integration configurations

### 🛠️ **Tools/**
External tools and services:
- API integrations
- Third-party configurations
- Tool-specific workflows

### 📝 **Templates/**
Reusable formats for consistent note-taking:
- Heartbeat template
- Reflection template
- Growth entry templates

### 📦 **Archive/**
Old or deprecated content preserved for reference.
