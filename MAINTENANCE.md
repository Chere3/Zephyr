# Maintenance Checklist

Run this checklist before opening a PR:

1. `bash scripts/docs_health_check.sh`
2. Confirm new daily notes use `Daily/YYYY-MM-DD.md`
3. Ensure new notes are linked from `INDEX.md` or relevant project notes
4. Keep anonymization policy in `Growth/` intact
5. Update `ROADMAP.md` when priorities shift

## Weekly sweep
- Fix broken wikilinks
- Archive stale notes
- Review roadmap progress
