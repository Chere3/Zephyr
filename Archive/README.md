# 📦 Archive

Old or deprecated content preserved for reference.

---

## 🗂️ What Goes Here

- Completed projects (no longer active)
- Deprecated systems
- Old notes that might be useful later
- Anything removed from active folders

---

## 📝 Archiving Process

1. Move file to `Archive/`
2. Add date prefix: `YYYY-MM-DD-original-name.md`
3. Add note at top: `*Archived: YYYY-MM-DD — Reason*`

---

*Nothing is deleted. Everything is preserved.*
