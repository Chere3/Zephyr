# 📈 Personal Growth

Space to document personal, professional, and emotional growth — all anonymized for public sharing.

## 🔒 Anonymization Policy

Any identifying information:
- **Companies/Organizations** → Changed to generic descriptions (e.g., "Tech Startup A", "Financial Corp B")
- **People's names** → Initials or descriptors (e.g., "Person M", "Person J")
- **Specific locations** → Generalized (e.g., "Home city", "Main office")
- **Sensitive numbers/data** → Rounded or categorized (e.g., "~50k salary" instead of exact number)
- **Confidential projects** → Described by function, not name (e.g., "Contract system" instead of "specific project")

## 📁 Structure

```
/Growth
├── README.md (this file)
├── Milestones/ (achievements and key moments)
├── Learnings/ (technical, professional, personal lessons)
├── Challenges/ (problems faced and how they were solved)
└── Reflections/ (deep thinking about direction, values, future)
```

## ✍️ Format Guide

**Always include:**
- Date
- Anonymized context
- What happened
- What you learned
- Impact or lesson

**Example:**

```markdown
# Successful negotiation

**Date:** 2026-02-03
**Context:** During a discussion with Tech Startup A

**What happened:** I proposed an architectural improvement that was initially rejected.

**What I learned:** Timing and political context are as important as the technical solution.

**Impact:** Next time I'll better contextualize before proposing significant changes.
```
