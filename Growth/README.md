# 📈 Growth

Personal psychology database — a searchable record of patterns, insights, and evolution.

---

## 🔒 Anonymization Policy

All identifying information is anonymized:

| Type | Format | Example |
|------|--------|---------|
| People | Initial | Person H, Person W, Person B |
| Companies | Generic | Large Corp, Tech Company, Previous Employer |
| Locations | Generalized | Home city, Main office |
| Roles | Removed | No "mentor", "boss", "supervisor" |
| Projects | Function only | "Contract system" not specific name |

---

## 📁 Structure

```
Growth/
├── Reflections/  → Deep thinking about identity, relationships, future
├── Challenges/   → Problems faced, patterns noticed, struggles  
├── Learnings/    → Lessons learned, growth moments
├── Milestones/   → Important achievements and breakthroughs
└── README.md     → This file
```

---

## ✍️ Entry Format

All entries follow this structure:

```markdown
# [Title]

**Date:** YYYY-MM-DD
**Context:** [Anonymized context]

**What happened:** [Description in first person]

**What I learned:** [Lesson or insight]

**Impact:** [Future action or realization]

---

## 🔗 Related Notes
- [[Link to related note]]
```

---

## 📝 Writing Guidelines

1. **First person only** — "I felt", "I learned", not "you felt"
2. **Anonymize everything** — Person H, not Hector
3. **Be honest** — This is for growth, not performance
4. **Link related notes** — Build the graph
5. **Date everything** — Context matters
