# Contributing

Thanks for improving this vault.

## Scope
This repository is a structured knowledge vault. Contributions should improve clarity, maintainability, and long-term discoverability.

## Branching
- Branch from `dev`.
- Use descriptive branch names:
  - `docs/...` for documentation-only changes
  - `chore/...` for maintenance and structure

## Commit style
Prefer Conventional Commits:
- `docs: ...`
- `chore: ...`
- `feat: ...` (only when adding meaningful new capabilities)

## Pull request checklist
- [ ] Explain the problem and why the change matters.
- [ ] List impacted areas (`Daily`, `Growth`, `Projects`, `Systems`, etc.).
- [ ] Include before/after examples if structure changed.
- [ ] Confirm links and references are valid.
- [ ] Confirm naming conventions stay consistent.

## Documentation standards
- Keep headings clear and stable.
- Favor short sections and explicit intent over long prose.
- Preserve anonymization rules for personal/psychological notes.
- Avoid adding sensitive personal data.
- Cross-link related notes when introducing new concepts.

## Quality bar
A good contribution makes the vault easier to navigate, easier to maintain, and safer to share.
